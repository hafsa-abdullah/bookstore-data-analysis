# Bookstore Data Analysis & Visualization

Data cleaning and analysis of a bookstore dataset using Python.

## What I did
- Checked for missing values and removed incomplete rows
- Calculated average book price by genre
- Found top-rated books (rating of 4.25 or higher)
- Visualized ratings count per book (bar chart) and genre share (pie chart)

## Tools
Python, Pandas, NumPy, Matplotlib, Google Colab

## Files
- `Bookstore-Data-Analysis.ipynb` - the notebook
- `books_dataset.csv` - the dataset
